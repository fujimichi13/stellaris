# ✦ Stellaris

A real-time path-traced Minecraft shaderpack for Iris, featuring physically based rendering, global illumination, and physically based atmospheric rendering.

![city](https://cdn.modrinth.com/data/cached_images/e074d39bcb67a7ccd837179ecb732847bfe80636.png)

# ✧ Features
* Path tracing
* Global illumination
* RTWSM
* Volumetric clouds
* Water caustics
* Water waves (inspired by [Revelation](https://github.com/HaringPro/Revelation/tree/dev) by HaringPro) 
* Water fog
* Ground truth ambient occlusion (GTAO)
* AgX tonemapping
* PBR (labPBR)
* World-space reflections
* Colored lighting
* Temporal anti-aliasing (TAA)
* Temporal anti-aliasing upscaling (TAAU)
* Volumetric lighting
* Physically based atmospherics
  - [A Scalable and Production Ready Sky and Atmosphere Rendering Technique](https://sebh.github.io/publications/egsr2020.pdf)
* Bloom
  - [Next Generation Post Processing in Call of Duty: Advanced Warfare](https://advances.realtimerendering.com/s2014/)
* Colored shadows
